# 画像ドット絵メーカー

画像をブラウザ上でドット絵に変換する Web アプリです。画像はサーバーに送信されず、端末内で処理されます。

## 必要環境

- Node.js `^20.19.0` または `>=22.12.0`（Vite 8 の要件）
- npm

```sh
node -v   # バージョン確認
```

## セットアップ

```sh
npm ci
```

## 開発サーバーで動作確認

```sh
npm run dev
```

ブラウザで http://localhost:5173/ を開きます。ソースを編集すると自動でリロードされます。

- ポートを変える: `npm run dev -- --port 3000`
- スマホなど同一ネットワークの別端末から確認する: `npm run dev -- --host` を実行し、表示される `Network:` の URL にアクセス

## 本番ビルドの確認

```sh
npm run build     # dist/ に出力
npm run preview   # ビルド結果を http://localhost:4173/ で配信
```

## 動作確認チェックリスト

1. 画像をドラッグ＆ドロップ、またはクリックして選択できる
2. 「ドットのサイズ」「色の数」「出力画像サイズ」スライダーで変換結果が更新される
3. 「マス目表示」のオン/オフが反映される
4. 「編集」ボタンとズーム（− / ＋）が動作する
5. 「JPGでダウンロード」で画像が保存される
6. 「もう一度変換」で初期状態に戻る

## ディレクトリ構成

```
.
├── index.html     # エントリーポイント

```
